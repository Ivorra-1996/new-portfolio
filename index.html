Sitio web · Three.js / GLSL

La Cripta

Prototipo de sitio para una coctelería con temática gótica: menú de cócteles, buscador A–Z, pantallas de estado y una página de detalle por cóctel.

  • Fondo animado hecho a mano con Three.js + GLSL: un flow-field donde líneas finas grises y blancas se agrupan y se separan sobre el fondo oscuro, en vez de resolverlo con una librería como Vanta.js.
  • Buscador A–Z pensado para un menú largo, sin depender de scroll infinito.
  • Estados de carga y de vacío tratados como pantallas propias, no como un spinner genérico.

E-commerce · Next.js

Pastelería

Storefront de e-commerce para una pastelería artesanal: catálogo de productos, carrito y flujo de pago.

  • Carrito persistente en localStorage, con estado global manejado por Context API.
  • Sin backend: catálogo hardcodeado, pensado para conectar una API más adelante sin rehacer la UI.
  • SEO cubierto con sitemap, robots.txt y generación de imagen para compartir en redes.

Sobre mí

Además de la parte visual, me interesa el criterio técnico detrás de cada interfaz: leer especificaciones de API antes de consumirlas, escribir documentación técnica que otra persona pueda seguir sin tener que preguntarme, adaptarme al stack que pida cada proyecto en vez de forzar siempre el mismo (React, Vue, Next.js y React Native pasaron por mis manos), y sostener una idea desde el prototipo temprano hasta un producto terminado.
