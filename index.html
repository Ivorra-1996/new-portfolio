[Captura / demo de La Cripta]

Sitio web · Three.js / GLSL

La Cripta

Prototipo de sitio para una coctelería con temática gótica: menú de cócteles, buscador A–Z, pantallas de estado y una página de detalle por cóctel.

  • Fondo animado hecho a mano con Three.js + GLSL: un flow-field donde líneas finas grises y blancas se agrupan y se separan sobre el fondo oscuro, en vez de resolverlo con una librería como Vanta.js.
  • Buscador A–Z pensado para un menú largo, sin depender de scroll infinito.
  • Estados de carga y de vacío tratados como pantallas propias, no como un spinner genérico.

[Captura / demo de SHIELD]

Dashboard interno · HTML/CSS/JS puro

SHIELD

Dashboard de monitoreo de riesgo de clientes, armado como un único HTML autocontenido: sin frameworks, con custom properties, Grid/Flexbox y SVG inline.

  • Tarjeta principal de score de riesgo con anillo de progreso hecho en SVG circular.
  • Chips de factores de riesgo con codificación de color por severidad.
  • Paneles con tabs (Información, Actividad, Documentación, Verificaciones, Familia) y un timeline de comentarios estilo GitHub.
  • Sidebar off-canvas tipo hamburguesa para mobile.
  • Decisión técnica: se reconstruyó por completo en Flexbox porque el entorno de renderizado final no soportaba CSS Grid — la prioridad fue que funcionara ahí, no la elegancia del layout ideal.

Sobre mí

Además de la parte visual, me interesa el criterio técnico detrás de cada interfaz: leer especificaciones de API antes de consumirlas, entender cómo encaja el frontend en una arquitectura de microservicios, escribir documentación técnica que otra persona pueda seguir sin tener que preguntarme, e interpretar auditorías de seguridad para no introducir problemas por accidente.
